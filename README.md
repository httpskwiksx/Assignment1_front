## About the Project

This project demonstrates basic HTML and CSS skills through separate webpages connected by a navigation bar.

## Tasks

- **Task 1 — Personal Page:** A profile card, information about me, interests, goals, an image, and external links.
- **Task 2 — Page Layout:** A header, navigation bar, sidebar, main content, and footer. The two-column layout uses CSS floats without Flexbox or Grid.
- **Task 3 — Tribute Page:** A page dedicated to Bang Chan, including his biography, career timeline, musical contributions, portrait, and links. Two Google Fonts are used.
- **Task 4 — Table and Form:** A student grades table with alternating row colors, a highlighted row, and merged cells. A feedback form includes name, email, role selection, radio buttons, comments, and a submit button.
- **Task 5 — Project Planning:** Pending. The topic, sitemap, and wireframes for an online clothing store will be prepared with a teammate.

## Technologies

- HTML5
- CSS3
- Google Fonts

## How to Run

1. Download or clone the repository.
2. Keep the original folder structure.
3. Open `navbar.html` in a web browser.
4. Use the navigation bar to open each task.

Opening the root `index.html` displays the personal page for Task 1.

No installation or build step is required. Google Fonts and external links require an internet connection.

## Project Status

Tasks 1–4 are implemented. Task 5 is in progress.

The feedback form demonstrates form controls and browser validation. It does not save or send feedback to a server.
